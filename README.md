# Presslay Media Player

Build the installer on Windows:

1. Install Node.js LTS from https://nodejs.org
2. Double-click `build.bat`
3. Run `dist\Presslay Media Player Setup 1.0.0.exe`

To try it without installing, double-click `run.bat`.

Features: playlists (rename, delete, import/export M3U), drag and drop files and folders, search, shuffle and repeat, 10-band equalizer with presets and live spectrum, album art from ID3 tags, mini player, media keys, light and dark theme, open-with support for mp3 and other audio files.

Shortcuts: Space play/pause, arrows seek and volume, N next, P previous, S shuffle, R repeat, M mute, Enter play selected, Delete remove selected.
